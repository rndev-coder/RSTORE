RSTORE – Social Media Services

RSTORE adalah website pemesanan layanan sosial media yang dirancang dengan tampilan modern dan responsif.

Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript

Struktur Kode

Proyek ini menggunakan konsep Single File, yaitu seluruh kode HTML, CSS, dan JavaScript digabungkan menjadi satu file agar lebih praktis, sederhana, dan mudah dikelola tanpa harus memisahkan file CSS maupun JavaScript.

Fitur

- Katalog layanan sosial media
- Kategori platform
- Form pemesanan
- Perhitungan harga otomatis
- Riwayat pesanan
- Integrasi WhatsApp untuk menghubungi admin
